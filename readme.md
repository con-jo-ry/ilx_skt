## Meta Repo of Skt. Texts

This is an attempt to create a meta-repository of Sanskrit etexts including metadata. It includes texts from GRETIL (taken from https://github.com/sanskrit-texts/gretil-corpus), the Digitial Sanskrit Buddhist Canon (https://www.dsbcproject.org/), Wikisource, Muktabodha, and some texts gathered by researchers at Hamburg University.

The structure of this repository and its scripts are being developed for the [Intellexus Project](https://intellexus.net/) and are licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0).
