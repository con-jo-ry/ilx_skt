namaḥ śrīherukāya //
sarvabhāvasvabhāvāgraṃ sarvabhāvabhayāpaham /
sarvabhāvanirābhāsaṃ sarvabhāvavibhāvinam //1//
taṃ praṇamya mahāvīraṃ khasamārthaṃ khanirmalam /
cakrasaṃvaratantrasya likhyate pañjikā mayā //2//
atra tantrādāv evaṃ mayetyādinā saṃgītikāreṇa kasmād upodghāto na kṛta iti codyam anūdya, kecid evaṃ parihārārthaṃ vyācakṣate bhagavato 'pratisṭhitanirśanārtham iti /
etad eva spasṭayati sarvātmani sadā sthita iti //
anye tu śatasāhasrikāt khasamān mūlatantrād uddhṛtatvāt tatraivādau mūlatantra evam ityādinā nirdiṣṭatvād atra taduttaratantre na kṛta iti /
ata āha --- anyatantrāvalīnānām arthānāṃ bahirvacanam uttaram iti //
apare tv aprakāśyadharmatayā deśyadeśakayor ekatā sūciteti /
tantramūrtayo hi buddhā bhagavanta iti vacanāt // [1.1]
prathamaṃ tāvad abhidhānābhidheyasaṃbandhaprayojanatatprayojanāny abhisamīkṣya dharmānusāriṇo 'pi prekṣāvantaḥ pravartanta iti /
ata eva tāny abhidhīyante //
athāta ity ārabhya iti śriherukābhidhāna ityādiparyanto granthasaṃdarbho 'bhidhānaṃ cakrasaṃvaram iti //
tena yad vācyaṃ śrīherukavajravārāhyādi tantrarūpaṃ tad abhidheyam //
abhidhānābhidheyalaksaṇaḥ saṃbandha ity eke / upāyopeyabhāvalakṣaṇaḥ saṃbandha ity apare // bhagavatīvineyajānāvatāramaṇḍalapraveśādiguhyābhiṣekaparyantaṃ prayojanam //
uttarakālaṃ tatphalāvāptiḥ prayojanaprayojanam iti // [1.2]
athetyādinā nipātasamudāyenāsyottaratantratvaṃ niścinoti /
athety ānantarye, khasamatantrānantaraṃ vakṣyamāṇam idaṃ vakṣye kathayiṣyāmīti saṃbandhaḥ // [1.3]
