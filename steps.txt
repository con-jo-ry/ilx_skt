How the corpus was made:

First:
- Downloaded first page of ied_works as a csv
- Used split_ied_works.py to create two separate csv files: gregil.csv and dsbc.csv

For gretil:
- Downloaded gretil data from https://github.com/sanskrit-texts/gretil-corpus
- gretil_compare_xml_to_bn_filelist.py: this script will (1) produce a csv file with a list of filenames in gretil_sa folder and their corresponding ".htm" references; (2) update gretil.csv to include columns for those file names, matched with the buddha nexus data where possible; (3) output some data on which files are missing / added in both dataets
- gretil_track_dsbc_in_gretil: added a column to gretil.csv indicating which files are originally from dsbc.
- gretil_find_body_tags.py: produces a full list of tei tags in the gretil files.
- gretil_produce_plain_txt.py: extracts body text from the gretil xml corpus and produces plain text versions. 

For DSBC:
- Downloaded complete index of all works (raw html from https://www.dsbcproject.org/canon-text/browse-by-list/1)
- dsbc_links_titles_from_index.py: creates src/dsbc/texts.csv, which contains links and titles as given in the index.html.
- dsbc_download_texts.py: downloads all linked html pages, saves them in "book" folders
- dsbc_html_to_xml.py: saves all html to corpus, extracts typist names and puts them in a tei header, removes all html tags. It also puts the url and title as given in index.html in the tei header.
- dsbc_produce_plain_txt.py: Exports the TEI files to corpus_txt
- dsbc_name_change_dry_run.py and dsbc_name_change.py: changed names from "book_1.xml" to have the work title included, adds book number as a new column in the CSV file.
- dsbc_update_header.py: Pushes metadata from CSV to the TEI header, adds licensing info, etc.

For Wikisource:
- Texts were collected manually by a student helper and listed in an excel file
- Scripts used to match the excel file created by the student with the files.
- The script wikisource_download_html_from_wikisource_csv.py downloads all links from the csv file
- The script wikisource_get_authors_from_html.py grabs whatever author info is available on those html pages (it's very minimal)
- I roughly standardised author names and text names and deleted various duplicate files.
- I stripped the student-created files of headers, add TEI headers, etc. 

### For muktabodha:
- Files acquired from a student helper who did some markup and made a metadata index
- Latest batch of files downloaded from muktabodha website (an addition 100 files or so)
- I restored the student modified headers to their original names
- I matched file names to the muktabodha website and renamed local versions for east of use.
- Added TEI headers to the file names with minimal metadata
