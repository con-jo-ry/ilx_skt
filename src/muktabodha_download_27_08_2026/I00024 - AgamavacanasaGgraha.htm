Description:
Description by Deviprasad Misra.
The title of this bundle is Āgamavacanasaṅgraha. It starts with some dhyānā ślokās but it mainly covers the Pratiṣṭhābhāga of Śaivāgama. It also deals with the nyāsa technique which is used for the sake of nityapūja and pratiṣṭha from different āgamās. The text mainly covers the Adhvaṣaṭkanyāsam which means mantrādhvanyāsam, padādhvanyāsam, varṇādhvanyāsam, bhuvanādhvanyāsam, tatvādhvanyāsam, kalādhvanyāsam, etc.
The bundle contains 49 folios and there are 5 to 6 lines in each folio. The size of this bundle is 14 cm / 2cm. The condition of the folio is a little bit damaged but the letters are very clean.
